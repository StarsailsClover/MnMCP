1. 网络传输层概述

  传输协议: RakNet (UDP)
  序列化:   Google Protocol Buffers 2 (proto2 syntax, 完整版非 lite)
  方向约定:
    _CH = Client → Host  (客户端发给房主/服务器)
    _HC = Host → Client  (房主/服务器发给客户端)
    _MSG = 双向通用

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

2. RakNet 游戏包头结构 (13 字节)

  偏移    大小    字段             说明
  ─────────────────────────────────────────────────────
  0x00    1       type             RakNet 消息类型
  0x01    4       guid1            玩家 GUID 部分 1
  0x05    4       guid2            玩家 GUID 部分 2
  0x09    2       cmd_id (LE)      协议消息 ID (ePBMsgCode 枚举值)
  0x0B    2       proto_sz (LE)    protobuf 载荷长度
  0x0D    ...     payload          protobuf 序列化数据

  解包伪代码:
    type     = buf[0]
    guid1    = uint32_le(buf[1:5])
    guid2    = uint32_le(buf[5:9])
    cmd_id   = uint16_le(buf[9:11])
    proto_sz = uint16_le(buf[11:13])
    payload  = buf[13 : 13 + proto_sz]

  注意: cmd_id 的合法范围是 0-10239 (0x27FE)，实际使用约 660 个值。
  特殊: cmd_id = 7000 时，payload 是 PB_Custom_Msg，内部用字符串名
        分发到 59 个子协议 (见下文第 6 节)。

8. 中继服务器对接指南

  8.1 解包迷你世界数据包
    1. 从 RakNet UDP 层取出应用层 payload
    2. 解析 13 字节游戏包头 → 得到 cmd_id + proto_sz
    3. 用 cmd_id 查 ePBMsgCode → 确定 message 类型
    4. 用对应 .proto 的 message 定义反序列化 payload
    5. 若 cmd_id = 7000 → 先反序列化为 PB_Custom_Msg →
       用 MsgName 字段确定子协议 → 再反序列化 MsgBuf

  8.2 代码生成
    protoc --java_out=./gen  proto_common.proto proto_ch.proto proto_hc.proto
    protoc --python_out=./gen proto_common.proto proto_ch.proto proto_hc.proto
    protoc --cpp_out=./gen   proto_common.proto proto_ch.proto proto_hc.proto

    注意: proto_ch.proto 和 proto_hc.proto 依赖 proto_common.proto，
    编译时需要一起传入或指定 --proto_path。

  8.3 协议翻译要点 (迷你世界 ↔ MC Java Edition)

    迷你世界概念          MC JE 等价物              cmd_id
    ────────────────────────────────────────────────
    PB_HeartBeatCH/HC     Keep Alive (0x21/0x23)   11/12
    PB_RoleEnterWorldCH   Login Start + Join Game   1001
    PB_SyncChunkDataCH    Chunk Data (0x27)         101

  8.4 坐标系差异
    迷你世界: sint32 定点数 (PB_Vector3)，需要 ÷ 某个比例还原浮点
    MC JE:    double 浮点 (绝对坐标) 或 fixed-point short (相对坐标)
    朝向: 迷你世界用 Yaw/Pitch float 或 packed uint32
          MC JE 用 angle byte (256 = 360°)
